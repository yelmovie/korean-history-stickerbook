# e뮤지엄 실물 사진 받기 가이드 (클릭 단위)

사이트: **https://www.emuseum.go.kr** (국립중앙박물관 e뮤지엄 — 전국 박물관 소장품 통합)
로그인 불필요. 실제 화면 기준으로 확인한 절차임 (2026-08-09).

## 순서

1. **https://www.emuseum.go.kr** 접속
2. 상단 메뉴 **[소장품 검색] → [상세검색]** 클릭
   (바로가기: https://www.emuseum.go.kr/detailSearch?searchType=8)
3. 상세검색 화면에서:
   - 맨 위 검색창에 **유물 이름** 입력 (아래 쇼핑 목록의 검색어 사용)
   - 아래 필터 중 **[공공누리유형]** 클릭 → **제1유형(출처표시)** 선택 ← ★ 이게 핵심. 이러면 나오는 건 전부 출처만 표기하면 쓸 수 있는 사진이야
   - **[고화질 이미지만 보기 (HD급 이상)]** 체크 권장
   - **검색** 클릭
4. 결과 목록에서 사진이 선명하고 유물 전체가 나온 걸 클릭 → 상세 페이지
5. 상세 페이지에서 두 가지 확인:
   - 아래쪽에 **"공공누리 출처표시 조건에 따라 이용할 수 있습니다"** 문구(=제1유형)가 있는지
   - 소장 박물관 이름 (크레딧에 적어야 함)
6. 이미지 옆/아래 **[이미지 다운로드]** 버튼 클릭 (사진 여러 장이면 제일 잘 나온 컷 선택. 이용목적 묻는 창이 뜨면 '교육' 선택)
7. 받은 jpg를 **아래 표의 파일명으로 이름 변경** 후
   `D:\isamgpt\19history\source-assets\photos-original\` 폴더에 넣기
8. 나한테 "사진 넣었어"라고 하면 변환(webp)·앱 연결·크레딧 표기까지 내가 처리
   (직접 하려면: `python scripts/optimize_assets.py` 말고 ASSET-PROMPTS.md의 한 줄 변환 명령 사용)

## 참고

- **국보·보물·사적으로 지정된 유물은 나한테 이름만 말해줘** — 국가유산청 OpenAPI로 내가 바로 받을 수 있어 (이미 22점 그렇게 받음). 위 목록은 지정이 안 됐거나 박물관 소장품이라 e뮤지엄 수동 확인이 필요한 것들이야.
- 안중근 의사 유묵은 **보물 지정**이라 내가 받을 수 있음 (유묵 여러 점 중 어떤 문구로 할지만 골라줘. 예: "見利思義見危授命")
- 유관순 열사 기록·광복 기념 자료·6·25 기록은 e뮤지엄보다 **독립기념관(i815.or.kr)·국사편찬위원회** 자료가 맞는데, 공공누리 유형이 제각각이라 받기 전에 꼭 유형 표기를 확인해줘.
