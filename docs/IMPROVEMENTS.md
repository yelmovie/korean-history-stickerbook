# 기능향상기 — 무엇을, 왜 고쳤나

만드는 과정은 `docs/MAKING.md` 에 있다. 이 문서는 **한 번 만든 것을 왜 다시 고쳤는지**만 모았다.
근거는 전부 이 저장소의 커밋과 `docs/` 안의 검수 문서다. 근거가 없는 항목은 적지 않았다.

읽는 법: 각 항목은 `무엇이 문제였나 → 어떻게 고쳤나 → 근거` 순서다.

## 1. 저작권 — "국가기관 자료니까 괜찮다"가 틀렸다

### 공공누리 유형을 사진 한 장 단위로 확인했다

**문제.** 국가유산청 OpenAPI 로 받은 사진을 기관 단위로 "공공누리니까 괜찮다"고 보고 리사이즈·WebP 변환해서 쓰고 있었다.

**확인.** 국가유산청은 사진마다 유형을 다르게 부여하고 그 값을 응답의 `imageNuri` 필드로 고지한다.
기관 일괄 고지는 존재하지 않았다. 원본 719장을 MD5 로 대조해 실제로 쓴 23장을 특정하고 한 장씩 확인했다.

**결과.** 제1유형 18장, **제4유형 5장.** 제4유형은 변경 금지 조건이라, 리사이즈·재인코딩한 5장 전부가 위반 상태였다.

**조치.**

| 사진 | 처리 | 이유 |
|---|---|---|
| `moon-jar` | 교체 | 제1유형인 「백자 달항아리(2005-1)」 국립중앙박물관본이 있었다 |
| `honcheonui` | 내림 | 국가유산청 보유 4장 전부 제4유형 |
| `hunminjeongeum` | 내림 | 보유 9장 전부 제4유형(간송미술관) |
| `janggyeong-panjeon` | 내림 | 재인코딩분 회수, 스티커 아이콘으로 되돌림 |
| `bulguksa` | 내림 | 같음 |

내린 사진 자리는 스티커 아이콘으로 되돌렸다. 화면이 비지는 않는다.
→ 근거: `e2f42ae`, 전수 감사 원본 `docs/KOGL-AUDIT.md`

### 출처 기록이 없는 자료는 아예 뺐다

**문제.** 그물추(`net-sinker`) 사진 1장은 어느 소장품에서 받았는지 기록이 남아 있지 않았다. 유형을 확인할 방법이 없다.

**조치.** "확인 불가 자료는 앱에 두지 않는다"로 정하고 사진·아이콘·스티커·문항 참조를 전부 제거했다.
해당 문항(q-s1-06)은 "두 유물이 함께 나온 것을 근거로 생활 모습을 추리한다"는 **문항 구조를 그대로 두고 유물만 바꿨다.**
빗살무늬 토기 + 그물추(물가 생활) → 민무늬 토기 + 반달돌칼(정착 농경). 정답 번호를 유지해 전체 정답 분포도 흐트러지지 않았다.
→ 근거: `9d5ea60`

## 2. 사실 정확성 — 학생이 잘못 배울 수 있는 것들

### 광개토대왕릉비 사진에 글자가 하나도 없었다

**문제.** e뮤지엄에서 받은 사진은 **탁본첩 4권을 덮은 채 찍은 겉표지**였다. 비문이 한 자도 안 보인다.
국립중앙박물관 소장 탁본은 공공누리 변경금지라 리사이즈조차 못 한다.

**조치.** 국립문화유산연구원 국가유산 지식이음(공공누리 제1유형 일괄 고지)에서 비석 실물 컬러 사진을 확보해 교체했다.

**뒤따른 수정.** 사진을 실물로 바꿨는데 설명은 '탁본'인 채 남아 있었다. 스티커 설명·문항 해설·출처 메모를 실물 사진에 맞게 고쳤다.
→ 근거: `9499cf1`, `c9e00e2`, `docs/CONTENT-REVIEW.md` "사진과 유물이 다른 종류인 경우"

### 태극기 4괘가 틀려 있었다

**문제.** 스티커용 태극기(i229)를 모서리별로 확대해 보니 **좌상에 리(☲), 우상에 건(☰)** 이 들어가
감(☵)이 아예 없고 리가 두 번 나왔다. 그림을 축소해 보면 티가 안 나는 종류의 오류다.

**조치.** 새 그림(i238)으로 교체하고 좌상 건 3획 · 우상 감 5획 · 좌하 리 4획 · 우하 곤 6획,
태극 위 빨강 아래 파랑을 모서리별로 확대해 하나씩 확인했다.

**같이 판단한 것.** e뮤지엄의 **옛 태극기 실물 사진**은 4괘 배치가 지금과 달라도 그대로 뒀다.
1949년 도안 통일 이전 자료라 오류가 아니라 사료다. 대신 학생이 현행 규격으로 오해하지 않도록 스티커 설명에 그 사실을 적었다.
**틀린 i229 는 삭제하지 않고 `12-rejected-inaccurate` 로 옮겼다.**
→ 근거: `b0157e4`

### 동학농민운동 깃발 — 확인되지 않은 것은 그림으로 말하지 않는다

**문제.** 그림의 태극이 좌우로 나뉘어 있었고(태극기의 태극은 위 빨강·아래 파랑), 글자가 한글 `보국안민` 이었다.
기록이 확실한 것은 한자 `輔國安民` 을 새긴 동도대장기다.
태극 도안은 오지영 보국안민 태극기 목판이 근거로 거론되나 **1894년 당시 실제 게양 여부는 확인되지 않았다.**

**조치.** 새 그림(i240)에서 태극과 글자를 모두 뺐다. 낡은 무명천과 대나무 장대만 남겼다.
보국안민은 그림이 아니라 **설명 문장**이 맡는다(스티커 hintLine·문항 해설).
→ 근거: `18f373a`, `49cfbad`, `docs/CONTENT-REVIEW.md` "2026-08-12 추가"

### 생성 이미지에 원칙을 세웠다

> **글자가 판독될 만큼 크게 보이는 문서 유물에는 생성 이미지를 쓰지 않는다.**
> 지어낸 한자·한글이 실제 문헌의 글자로 오인되면 그 자체가 왜곡이기 때문이다.

새로 만든 그림을 이 기준으로 걸러 **37종 채택 / 12종 미채택**.
미채택은 훈민정음·직지·애국가 악보·글씨 있는 태극기·獨立精神 족자 등 지어낸 글자가 크게 보이는 것들이다.
대신 문서 유물 5종(조선왕조실록·동의보감·대동여지도·독립신문·기미독립선언서)은
**검증된 공공누리 제1유형 실물 사진에서 아이콘을 만들었다.**

형태가 안 맞아 되돌린 것도 있다. 빗살무늬 토기는 새 그림의 바닥이 평평해 실물(뾰족한 바닥) 및 해설과 어긋났고,
백자 달항아리는 흰 자기라 종이 바탕에서 안 보였다.
→ 근거: `1b4b084`

## 3. 문제 품질 — 글자 수만 봐도 답이 보였다

**문제.** 정답 위치가 한쪽에 몰려 있었고, 정답 보기만 유독 길었다.
오답 중에는 초등학생도 한눈에 아니라고 알 만한 것이 섞여 있어 생각할 여지가 없었다.

**조치 (28문항 전수).**

- 정답 위치 재분배 0/1/2/3 = 6/6/6/5 (인덱스가 있는 23문항 기준)
- 보기 글자 수 편차 14% 이내, **정답만 단독으로 긴 문항 0개**
- 유치한 오답 → 초등 5~6학년의 실제 오개념(시대 혼동, 자료의 과잉 해석, 기구 용도 혼동)으로 재작성
- 5~6학년군 밖 용어('성리학'·'우열' 등) 제거
- 단정 표현 완화 (`~였다` → `~로 알려져 있어요 / ~로 보여요`)
- 근거를 못 찾은 서술 삭제 — 측우기 "세금에 활용"은 빼고 "농사 형편을 헤아리는 데 쓰인 것으로 보여요"로 축소

**남겨 둔 것.** 학계에 이견이 있는 서술(첨성대 용도, 고인돌 성격, 빗살무늬 토기 뾰족바닥 등)은
완곡 표현으로 두고 `contentReviewNeeded` 플래그로 표시했다. 사람 검수 목록은 `docs/CONTENT-REVIEW.md` 에 그대로 있다.
→ 근거: `431744f`, `7cf8d64`

## 5. 교실에서 쓸 수 있게

### 학교망에서 글꼴이 깨지지 않게

**문제.** 구글 폰트를 외부에서 받아오면 학교망 차단 시 글꼴이 통째로 무너진다.

**조치.** Jua(SIL OFL)를 **셀프호스팅**으로 바꿨다. 외부 요청 0.
unicode-range 서브셋이라 브라우저는 실제로 화면에 나온 글자가 든 조각만 내려받는다.
→ 근거: `3ba68a3`, `index.html`

### 와이파이가 끊겨도 수업이 이어지게

앱 셸 + 그림 + 폰트 + 효과음을 서비스워커로 precache 한다(약 13MB).
아직 들어가지 않은 스테이지까지 미리 캐시되므로 수업 도중 와이파이가 끊겨도 진행이 멈추지 않는다.
BGM 6.5MB 는 설치를 느리게 만들어 precache 에서 빼고, 처음 들을 때 런타임 캐시로 잡는다.
→ 근거: `vite.config.ts` 의 workbox 설정

### 전자칠판에서 보이게

글자 크기 기준을 `2cqh`(900px 높이 기준 18px)로 정하고 전 화면에 일괄 적용했다.
1280×720 / 1920×1080 / 1024×768 세 해상도에서 넘침 0, 문서 스크롤 0 을 확인했다.
→ 근거: `69b3eed`, `431744f`

### 소리 크기를 조절할 수 있게 (2026-08-12)

**문제.** 배경음·효과음이 켬/끔만 있었다. 교실에서는 "조금만 줄여 주세요"가 필요한데 방법이 없었다.

**조치.** 설정 → 소리에 배경음악·효과음 볼륨 막대를 넣었다.
값은 `save` 스키마를 건드리지 않고 별도 키 `kh_volume_v1` 에 저장한다.
막대를 0% 로 내리면 켬/끔 토글도 함께 꺼짐으로 바뀌고, 꺼진 상태에서 다시 켜면 100% 로 돌아온다.
**막대와 토글이 서로 다른 상태를 보이는 일이 없다.**
→ `src/utils/audio.ts`, `src/components/SettingsPanel.tsx`

### 학생용 가이드와 의견 보내기 (2026-08-12)

**문제.** 설정 안에 교사용 가이드만 있어서, 조작을 모르는 학생이 물어볼 곳이 앱 안에 없었다.

**조치.** 학생용 가이드 섹션을 새로 넣었다(유물 관찰·발굴 문지르기·선잇기·카드 놓기·스티커 붙이기·틀려도 다시 하기).
문구는 하드코딩하지 않고 `public/data/teacher.json` 에 데이터로 뒀다. 교사가 문장을 바꿀 수 있어야 해서다.

의견 보내기는 **양식 복사 방식**으로 만들었다. 메일 주소를 화면에 노출하지 않고 mailto 링크도 쓰지 않는다.
학생 화면에 개인 연락처가 뜨는 것을 피하기 위해서다.
"무엇을 하다가 / 어떤 화면에서 / 어떻게 됐는지" 세 줄을 복사해 선생님께 전하도록 안내한다.

### 폰트 폴더 점검 (2026-08-12)

파일 탐색기나 `du` 로 보면 `public/assets/fonts/` 가 11MB 로 나온다. **실제 크기가 아니다.**

| 측정 | 값 |
|---|---|
| 파일 수 | 88개 (woff2 87 + jua.css 1) |
| **실제 바이트 합계** | **878 KB** (woff2 만 834 KB) |
| 디스크 할당량 | 약 11 MB |

이 볼륨의 클러스터 크기가 128 KB 라서, 평균 10 KB 짜리 파일 88개가 각각 128 KB 씩 차지한 것으로 집계된다
(88 × 128 KB ≈ 11.3 MB — 계산이 정확히 맞는다). 배포·전송에는 실제 바이트만 나간다.

**결론: 옮기거나 지우지 않는다.** 근거는 셋이다.

1. **실제 용량이 작다.** 878 KB 는 precache 총량 13.4 MB 의 6% 다.
2. **정상 접속에서는 이보다도 훨씬 덜 받는다.** `jua.css` 가 `unicode-range` 로 서브셋을 나눠 두어,
   브라우저는 화면에 실제로 나온 글자가 든 조각만 내려받는다.
3. **하나라도 빼면 오프라인에서 글자가 깨진다.** 서비스워커가 87개 전부를 precache 한다(`globPatterns` 에 `woff2` 포함).
   어떤 조각이 필요한지는 앞으로 추가될 문항·스티커 문구에 따라 달라지므로, 지금 안 쓴다고 지우면
   문구를 한 줄 고치는 순간 그 글자만 시스템 폰트로 튀어나온다. 되돌리기 어려운 종류의 사고다.
